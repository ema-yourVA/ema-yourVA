## How I build

- **Free tier first.** Start with what the client already pays for, and only upgrade when the volume genuinely calls for it.
- **Passwords and keys never reach the browser.** Anything sensitive stays on the server, where a visitor cannot read it, and the workflow reaches it through a small go-between.
- **Written up for handover.** Every build comes with notes, so someone else can run it without me.
- **Honest about AI.** If AI runs inside the system itself, the case study says so. If AI only helped me build it, it says that too. The design, the decisions and the testing are mine.
