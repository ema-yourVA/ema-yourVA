## How I build

- **Free tier first.** Start on what the client already pays for, upgrade only when volume actually demands it.
- **Secrets stay server-side.** Nothing sensitive ships in a browser bundle. Credentials live in script properties or environment variables, reached through a relay.
- **Documented for handover.** Every build is written up so someone else can run it without me.
- **Honest about AI.** Where a model runs inside a pipeline, the case study says so. Where AI only assisted the build, it says that too. The architecture, decisions, and testing are mine.
